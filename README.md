# AI 机理深度研习系列

> 从数学推导到工程实现，五册 126 讲，系统理解大模型、信息论、量子计算、Agent 与运筹学的底层原理。

---

## 项目简介

这是一套从零推导的 AI 技术研习讲义，覆盖大模型核心机理、信息论科研方法论、量子计算视角、智能体系统设计、以及 AI 时代的运筹学决策。每讲包含完整数学推导、直觉解释、常见误区、可运行代码和梯度思考题。

**特点**：
- 数学推导不跳步，每一步都有解释
- 每讲配可运行的 Python 代码（numpy / PyTorch / scipy）
- 💡 直觉框 + ⚠️ 误区框，拦截常见理解偏差
- 思考题分基础 / 进阶 / 开放三档
- 多格式交付：Markdown / HTML / PDF

## 使用方式

### Markdown 版（推荐编辑 / 二次开发）
用 [Typora](https://typora.io/) / [Obsidian](https://obsidian.md/) / VS Code 打开，数学公式自动渲染。

### HTML 版（推荐日常阅读）
直接双击 `HTML版/AI机理深度研习系列.html`，无需联网。
- 左侧目录可折叠跳转
- 深浅色主题切换
- 响应式布局（手机可看）

### PDF 版（推荐打印 / 离线）
`PDF版/` 目录下，xelatex 编译，中文正常显示，公式原生排版。
